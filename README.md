# Ethereum Gas Spenders and Transaction Activity

Analysis of the Ethereum blockchain focused on who pays the most, what kind of activity is happening, and what the nerwork usage pattern
looks like. Data is intentionally tiny, limited to 20-row dataset for practice purposes only. This is my first project on Dune. My first tiny dashboard. :') It might seem very simple but I'm keeping it. 

### 1. Questions

**Q1 - WHO are the biggest gas spenders?**
Who are the top wallets / contracts spending the most gas? Are they whales, bots, or major protocols?

**Q2 - WHAT is the transaction type?**
What is the transaction activity? 

**Q3 - HOW BIG is the transaction**
What is the network usage pattern?

### 2. Workflow

1. Explored Ethereum tables on Dune Analytics
2. Querried and snapshotted dataset, downloaded as CSV
3. Re-uploaded CSV as custom data source in Dune
4. Wrote 3 queries for Q1, Q2, Q3
5. Built visualizations and final dashboard
